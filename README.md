# HalluciGuard Frontend

A cinematic, evidence-first landing experience for HalluciGuard.

> **Don't trust the answer. Trace the evidence.**

## Experience

- Pale-green investigation hero with a live claim trace
- Moving evidence-format records
- Scroll-revealed capability field
- Five-agent orchestration visualization
- Interactive evidence relationships
- Verification pipeline, FAQ, and contact preview
- Responsive layouts and reduced-motion support

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The contact form is intentionally a non-transmitting preview until a team inbox or form endpoint is selected. Examples are curated and clearly labelled; live AI verification is not connected.
